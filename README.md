# 农产品供销预测系统

这是一个基于阴阳八卦周易五行理念的农产品供销预测系统，通过传统易学智慧，为农产品市场提供参考性预测。

## 功能特点

- 结合五行属性（金木水火土）对应不同农产品类别
- 基于六十四卦象进行市场预测
- 提供市场趋势、价格走向、供需关系和宜忌建议
- 直观的卦象显示和预测结果展示

## 使用方法

1. 打开`index.html`文件
2. 选择对应的农产品类别（按五行属性分类）
3. 点击"开始占卜"按钮
4. 系统将随机生成一个卦象并提供相关的市场预测

## 预测结果解读

预测结果包含以下几个方面：

- **市场趋势**：农产品市场的整体发展方向
- **价格走向**：未来一段时间内价格的可能变化
- **供需关系**：市场供需平衡状况分析
- **宜忌建议**：基于五行和卦象的行动建议

## 技术说明

- 纯前端实现，无需服务器支持
- 使用HTML5、CSS3和JavaScript开发
- 占卜结果基于随机算法，结合五行相生相克原理

## 注意事项

本系统仅供参考和娱乐，实际农产品市场受多种复杂因素影响，请勿将预测结果作为投资决策的唯一依据。
